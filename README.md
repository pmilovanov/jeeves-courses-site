# The Jeeves Courses — reading-room site

This repository holds the **built site** for The Jeeves Courses, served at
**https://pmilovanov.github.io/jeeves-courses-site/** — audio courses of
unusual thoroughness, narrated by Jeeves:

- **The Parliament of Machines** — distributed systems
- **The Anatomy of the Continuum** — real analysis, in two seasons
- **Reading the Mind of the Machine** — mechanistic interpretability

Each course is a season of spoken-word episode scripts with a formal Desk
Volume (statements, complete proofs, tiered problems), served here for
reading online and for download (PDF, EPUB, Markdown).

Everything in this repository is a generated artifact, published
automatically from a private source repository — edits here would be
overwritten on the next publish. Corrections and correspondence to
[@pmilovanov](https://github.com/pmilovanov).
